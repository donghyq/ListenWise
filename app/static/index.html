    01
    在声息中连接模型
    连接 DeepSeek、OpenAI 或企业网关，让模型生成大纲和讲稿，再在声息中审阅与导出。
    所选材料会发送给你连接的模型服务。正在检查模型配置
    
        
    02
    通过本机 Agent 整理
    让 Codex 等 Agent 读取你选择的材料，生成内容并回写声息，然后继续审阅与导出。
    需要先安装声息 Skill；无需在声息中配置模型密钥。
    
        
    03
    复制给外部 AI 助手
    把选定的材料包复制到任意 AI 助手（ChatGPT、千问等）生成 Markdown，再将结果粘贴回声息审阅。
    适合偶尔整理文章；无需配置模型密钥。
    
      
    
      
    声音能力
    从文字到有声书
    好文章可直接原文朗读；要点速听与专题学习自动分章，合成 m4b 有声书，AirDrop 到 iPhone「图书」逐章收听。校对脚本用浏览器朗读即可，不耗 API。
    
      
    Agent 使用方式
    安装 Skill，在对话中调用
    安装声息 Skill 后，在 Agent 对话中输入 $lawflow 和你的任务。声息会保留材料范围与审阅步骤。
