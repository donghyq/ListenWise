# 声息 Shengxi

**把没有时间读完的东西，带到路上。**

声息是一款本地优先的桌面应用，把收藏的文章、报告和笔记变成适合碎片时间收听的内容。你可以保留原文直接朗读，也可以让 AI 提炼要点、规划章节——所有生成内容经人工确认后才变成音频，数据和模型密钥始终保存在本机。

## 功能特性

- **多种导入方式**：粘贴公众号或公开网页链接（抓取后可展开核对全文）、上传 PDF / DOCX / TXT / Markdown，或直接粘贴正文。
- **两种收听形态**：
  - **原文朗读** — 不经 AI 改写，直接生成语音；
  - **播客风改写（默认）** — AI 按目录或内容逻辑划分章节，逐章写成播客风讲稿再合成音频。改写深度三档可选：原文转译（不丢信息）/ 提炼（压缩速听）/ 扩充（补背景讲得更透）。
- **章节页即落地页**：书架点进项目直接落在「章节 · 收听」视图——顶部播客播放器与下方本章正文联动，播放时当前句高亮并自动滚屏；**点击正文任意句子可直接从该句开始收听**。
- **先生成第 1 章试听**：大纲确认后，可先花约 20 秒生成第 1 章正文与试听音频验证风格，满意后再从第 2 章断点续写全篇，第 1 章不重复生成。
- **划选句子直接提修改意见**：在章节正文划选任意段落，即可触发「精简这段 / 解释术语 / 引用并提意见」，生成候选稿与原稿左右对照；确认采用后可自动重录本章音频。
- **全局驻留迷你播放器与快捷键**：播放中切换到素材、大纲或返回书架时，窗口底部自动浮起迷你播放条，收听不中断；支持桌面快捷键（`Space` 播放/暂停、`←/→` ±15 秒、`[/]` 切章、`M` 标记本章已学）与睡眠定时。
- **音频输出**：试听片段、浏览器校对朗读、分章/整篇 MP3、带章节标记的 M4B 有声书；支持响度归一、首尾淡入淡出与可选片头片尾。
- **带到手机听**：点击项目顶部的「带到手机听」，可在同一张书签卡上切换「仅带走本书」或「带走整个书架」二维码（支持多网卡局域网 IP 切换），手机在同一 Wi-Fi 下扫码即可按章收听、对照文稿、离线缓存到手机或下载整书 ZIP。
- **文档导出**：Markdown 与 DOCX，可按节导出。
- **书架整理与自动导入**：支持收藏夹标签、系列合集聚合、画廊/紧凑列表视图切换与批量管理；可订阅公开 RSS / Atom 来源或监听本地文件夹自动导入。
- **学习进度**：章节阅读进度与"标记已学"状态在阅读页和音频页之间共享。

## 工作流程

```
导入材料 ──► 选择收听方式 ──► 大纲 / 脚本 ──► 人工审阅确认 ──► TTS 合成 ──► 试听 / 导出
   │              │                │                                    │
 网页/文件      原文朗读          AI 播客风改写，标注来源回链        MP3 / M4B / DOCX
 粘贴正文      播客风改写        自动成稿，可逐章修改、重做         带章节标记
                （深度三档）
```

## AI 协作方式

原文朗读不依赖文本模型。选择播客风改写时，声息提供三种协作方式：

| 方式 | 怎么使用 | 材料去向 |
| --- | --- | --- |
| 在声息中连接模型 | 在应用内配置 OpenAI、DeepSeek 或任意 OpenAI 兼容接口 | 用户明确允许后，所选材料才会发送给配置的模型服务 |
| 使用本机 Agent | 安装仓库中的[声息 Agent Skill](skills/lawflow/SKILL.md)，让支持 Skill 的 Agent 读取项目、生成内容并回写 | 由所使用的 Agent 和模型服务决定；声息内无需另配文本模型密钥 |
| 复制给外部 AI 助手 | 复制选定材料包，在外部助手中生成 Markdown，再粘贴回声息审阅 | 用户主动复制的材料进入对应服务 |

**待核验提示不等于事实核查已经完成。** 生成内容不能直接代替专业判断。

## 快速开始

### 平台支持一览

| 平台 | 使用方式 | 语音与导出支持 |
| --- | --- | --- |
| **macOS（Apple Silicon）** | 下载 `.dmg` 桌面安装包，或从源码启动 | 内置 macOS 本地离线语音（`say` / 婷婷增强版）、Edge TTS、云端 TTS；导出文件自动在访达（Finder）定位 |
| **Windows（10 / 11）** | 从源码启动，或使用 `scripts/build_windows_app.ps1` 打包桌面版 | 内置 Windows SAPI 本地离线语音、Edge TTS、云端 TTS；导出文件自动在资源管理器定位 |
| **手机端（iOS / Android）** | 电脑端点击「带到手机听」生成二维码，手机连同一 Wi-Fi 扫码即听 | 支持按章连播、文稿同步滚动、睡眠定时、**浏览器离线缓存（电脑关机也能听）**、整书 ZIP 打包下载与学习进度回传 |

### 方式一：下载桌面安装包（macOS）

前往 [Releases](https://github.com/hey-elaine/lawflow/releases/tag/v0.1.2) 下载最新 `v0.1.2` 安装包（`Shengxi-0.1.2-macOS-arm64.dmg`）。

安装与首次打开说明：
1. 打开 `.dmg`，将「声息.app」拖入「应用程序（Applications）」。
2. 因安装包采用开发阶段临时签名（尚未进行 Apple Developer ID 公证），首次打开若提示无法验证开发者，请在访达「应用程序」中**按住 Control 键点击「声息」→ 选择「打开」**（或在「系统设置 → 隐私与安全性」中点击「仍要打开」）。
3. 如需合成完整 MP3 与 M4B 有声书，请确保本机已安装 FFmpeg（macOS 可执行 `brew install ffmpeg`）。

### 方式二：从源码运行

macOS / Linux：

```bash
git clone https://github.com/hey-elaine/lawflow.git
cd lawflow
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 -m uvicorn app.main:app --host 127.0.0.1 --port 8080
```

Windows（PowerShell）：

```powershell
git clone https://github.com/hey-elaine/lawflow.git
cd lawflow
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8080
```

在浏览器打开 <http://127.0.0.1:8080>。首页提供完整示例项目，可以先试听再决定是否导入自己的材料。

补充说明：

- **FFmpeg**（含 `ffprobe`）：完整 MP3 合成与 M4B 导出需要；仅导入、整理和审阅文字不需要。Windows 可用 `winget install Gyan.FFmpeg`。
- **文本模型**：在应用"本地设置"中连接；使用本机 Agent 协作或原文朗读时不必配置。
- **语音合成**：macOS / Windows 均有免费离线的本机语音可选，无需任何密钥；云端 TTS 为可选项。
- **桌面打包**：macOS 见[桌面版发布说明](docs/desktop-release.md)，Windows 见 [Windows 运行与打包说明](docs/windows-release.md)。

### 三分钟上手指南（从一篇文章到随身收听）

1. **导入并核对原文**：打开声息进入「我的书架」，在顶部粘贴公众号/网页链接（点击「预览文章」可展开检查全文与结尾是否完整），或直接拖入 PDF / DOCX / Markdown 文件。
2. **选择怎么听**：
   - 想原汁原味听全文：选 **「原文朗读 · 不改写」**，无需配置大模型即可直接用本机语音或 Edge TTS 生成音频；
   - 想听条理清晰的播客讲解：选 **「播客风改写」**，并按需选择改写深度（**原文转译** / **提炼** / **扩充**）。
3. **分章与 20 秒试听**：在「大纲」页确认章节划分后，可先点 **「先生成第 1 章试听」** 用 20 秒验证改写风格与音色；满意后点 **「继续生成剩余章节」** 从第 2 章自动续写。
4. **声文同频收听与润色**：在「章节 · 收听」页播放时，点击正文任意句子可直接跳转朗读；遇到不满意的段落，用鼠标划选文字即可让 AI 精简或重写该段，确认采用后自动更新该章音频。
5. **带到路上听**：点击项目右上角 **「带到手机听」**，用手机相机扫码即可在通勤路上按章收听、设置睡眠定时，或点击「离线缓存 / 下载全部」保存到手机离线播放。

## 技术栈

| 层 | 实现 |
| --- | --- |
| 后端 | Python · FastAPI · SQLite · Pydantic |
| 前端 | 原生 HTML / CSS / JavaScript（无构建步骤） |
| 语音合成 | edge-tts（默认）及 OpenAI 兼容 TTS 接口 |

## 数据与隐私

- **本地存储**：文章、项目、进度和生成结果默认保存在本机。桌面版路径：macOS 为 `~/Library/Application Support/LawFlow/data/`，Windows 为 `%LOCALAPPDATA%\LawFlow\data`；从源码运行使用仓库下的 `data/`。导出目录可在应用中设置。
- **网络边界**：桌面应用监听局域网，但局域网设备只能访问扫码领取的收听页（`/m/` 限时链接），无法访问声息的其他功能。声息目前没有公共业务后端。
- **第三方服务**：使用外部文本模型或语音服务时，相关内容会发往用户选择的服务。调用前请确认材料有权发送。
- **网页检索**：公开网页检索仅用于发现候选来源，用户确认导入后才会用于后续整理。

## 当前边界与路线图

**已支持：手机扫码收听。** 在音频页生成二维码后，手机与电脑连同一个 Wi-Fi 时扫码，即可在浏览器里按章收听、边听边看文稿（自动随播放滚动）、±15 秒快进后退、下载章节、续听上次进度；也可一键下载整书 ZIP（逐章 MP3 + 讲稿 TXT），解压后离线收听。手机页还支持**离线缓存**：把章节音频存进手机浏览器，之后即使电脑关机，页面里已缓存的章节照样能听；离线时标记的「已学」会暂存，重新连上电脑后自动同步。在 iPhone Safari 里「分享 → 添加到主屏幕」，收听页会以独立图标全屏打开，接近原生 App 的体验。手机上标记的「已学」会同步回电脑。链接默认 7 天有效，可随时吊销，且只在声息运行时可访问——电脑退出或睡眠时，手机页会暂时打不开（已缓存或已下载到手机的内容不受影响）。

**尚未实现**：从外部网络（不同 Wi-Fi）收听——计划通过加密临时上传的中转实现，未完成；受浏览器限制，主屏幕图标重新打开时仍需声息在线加载页面本身，完全离线启动需等中转阶段；手机端暂时是网页，还不是可安装的原生应用。

M4B 带章节标记，但不能保证隔空投送后直接进入 iPhone“图书”；可先导入电脑的“图书”再通过访达同步到手机。

移动端路线图（标记"未实现"的阶段均无确定发布日期）：

| 阶段 | 状态 |
| --- | --- |
| 1. 逐章音频与章节信息 | 已实现（分章学习逐章合成 MP3） |
| 2. 局域网扫码领取 | 已实现（单书二维码 + 整座书架二维码，支持多网卡 IP 切换与随时吊销） |
| 3. 手机网页收听 | 已实现（按章播放、倍速、整书 ZIP 下载、断点续听、已学回传） |
| 4. 外部网络中转 | 未实现：加密临时上传 + 可过期中转链接，支持不在同一 Wi-Fi 时收听 |
| 5. 离线与安装 | 首版已实现（IndexedDB 离线缓存）；未实现：PWA 完全离线启动和可安装应用 |
| 6. 真机验收后扩展 | 未实现：锁屏播放与耳机控制真机验证；必要时再评估独立 iOS 客户端 |

扩展到外部网络的中转路径预计需要少量按用量计费的临时存储和网络流量；只有用户主动使用时才涉及上传。加密、链接失效和数据删除机制会先于对外开放完成。

## 路线图

路线图区分已落地首版、继续打磨中的能力和尚未开工的规划；不把候选设计写成已完成能力。

### 已实现

以下能力已有源码实现和本地测试/验收路径，后续仍可能按使用反馈继续打磨：

- **桌面端听读同步与点句即听**：主播放器驱动章节正文逐句高亮与自动滚屏，点击正文任意句子直接跳转播放。
- **正文划词快捷修改与单章候选稿对照**：划选正文句子直接向 AI 提修改意见，确认采用后可自动重录该章音频。
- **第 1 章快速试听与逐节生成断点续作**：先生成第 1 章试听验证风格，后续生成或中断重试时自动跳过已完成章节。
- **全局驻留迷你播放器与桌面快捷键**：跨页签/回书架保持底部迷你播放条控制，支持 `Space`、`←/→`、`[/]`、`M` 快捷键与桌面睡眠定时。
- **手机书架聚合与单书随身书签**：支持单书二维码与整架书二维码切换、多网卡局域网 IP 切换、手机端整书 ZIP 下载与进度回传。
- **事实核对面板**：抽取原文日期、数字和法规名，核对成稿保留情况。
- **睡眠定时器与继续收听**：按设定停止播放，并在书架和音频页接续上次进度。
- **AI 分章理由**：AI 分章时给出分章理由。
- **讲稿多版本切换与未确认草稿清理**：优先展示已确认且有就绪音频的正式版，支持一键清理多余历史草稿。
- **书架整理与批量管理**：支持收藏夹、系列合集聚合、画廊/紧凑列表视图切换与多选批量管理。
- **文件夹监听自动导入**：监听指定本地文件夹，把新文件导入「收件箱」项目。
- **音频后期处理**：响度归一、章节淡入淡出、可选片头片尾。
- **超长文自动分段处理**。
- **通知中心与失败重试**。
- **重复导入检测**。
- **材料未变时复用上次大纲**。
- **Token 用量统计**。
- **诊断接口**。
- **局域网限流与仅本机模式**。
- **CI**：push 到 main 或提交 pull request 时执行依赖安装、前端脚本语法检查和单元测试。
