# 声息 Shengxi

**把没有时间读完的东西，带到路上。**

声息是一款本地优先的桌面应用，把收藏的文章、报告和笔记变成适合碎片时间收听的内容。你可以保留原文直接朗读，也可以让 AI 提炼要点、规划章节——所有生成内容经人工确认后才变成音频，数据和模型密钥始终保存在本机。

## 功能特性

- **多种导入方式**：粘贴公众号或公开网页链接（抓取后可展开核对全文）、上传 PDF / DOCX / TXT / Markdown，或直接粘贴正文。
- **三种收听形态**：
  - **原文朗读** — 不经 AI 改写，直接生成语音；
  - **先听要点** — 把长文章压缩为约 5 分钟的速听稿，超长时自动兜底压缩；
  - **分章节学习** — 按目录或内容逻辑划分章节，逐章成稿、逐章收听，支持记录每章的学习进度。
- **章节正文与音频一起查看**：目录展示每章的正文和音频状态，选中后可以阅读、播放、调倍速、保存音频或单独编辑本章。
- **按意见修改讲稿**：针对一章填写修改意见，先对照原稿与候选稿，再选择采用或保留原稿。保存修改后，改动章节及整篇音频标为待更新；其他章节继续可听。章节划分不合适时，可按合并、拆分或排序意见生成新大纲，确认后再生成新版本，旧稿保留。
- **音频输出**：试听片段、浏览器校对朗读、整篇 MP3、带章节标记的 M4B 有声书；支持音色增强与语速调整。
- **发送到手机**：生成一次性领取链接和二维码，手机在同一 Wi-Fi 下扫码即可按章收听、对照文稿，或一键下载整书 ZIP（逐章 MP3 + 讲稿 TXT）离线收听；链接可随时吊销。
- **文档导出**：Markdown 与 DOCX，可按节导出。
- **收藏夹与订阅**：书架按收藏夹归类；可订阅公开 RSS / Atom 来源，定期生成待审速听稿。
- **学习进度**：章节阅读进度与"标记已学"状态在阅读页和音频页之间共享。

## 工作流程

```
导入材料 ──► 选择收听方式 ──► 大纲 / 脚本 ──► 人工审阅确认 ──► TTS 合成 ──► 试听 / 导出
   │              │                │                                    │
 网页/文件      原文朗读          AI 生成，标注来源回链            MP3 / M4B / DOCX
 粘贴正文      先听要点          用户可逐节修改、重做             带章节标记
              分章节学习
```

## AI 协作方式

原文朗读不依赖文本模型。选择"先听要点"或"分章节学习"时，声息提供三种协作方式：

| 方式 | 怎么使用 | 材料去向 |
| --- | --- | --- |
| 在声息中连接模型 | 在应用内配置 OpenAI、DeepSeek 或任意 OpenAI 兼容接口 | 用户明确允许后，所选材料才会发送给配置的模型服务 |
| 使用本机 Agent | 安装仓库中的[声息 Agent Skill](skills/lawflow/SKILL.md)，让支持 Skill 的 Agent 读取项目、生成内容并回写 | 由所使用的 Agent 和模型服务决定；声息内无需另配文本模型密钥 |
| 复制给外部 AI 助手 | 复制选定材料包，在外部助手中生成 Markdown，再粘贴回声息审阅 | 用户主动复制的材料进入对应服务 |

**待核验提示不等于事实核查已经完成。** 生成内容不能直接代替专业判断。

## 快速开始

### 方式一：下载安装包

前往 [Releases](https://github.com/hey-elaine/lawflow/releases) 下载安装包（Apple Silicon）。注意：已发布版本可能落后于 `main` 分支；当前包采用临时签名、尚未完成公证，安装要求见[版本说明](https://github.com/hey-elaine/lawflow/releases/tag/v0.1.0-beta.1)。

### 方式二：从源码运行

```bash
git clone https://github.com/hey-elaine/lawflow.git
cd lawflow
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 -m uvicorn app.main:app --host 127.0.0.1 --port 8080
```

在浏览器打开 <http://127.0.0.1:8080>。首页提供完整示例项目，可以先试听再决定是否导入自己的材料。

补充说明：

- **FFmpeg**（含 `ffprobe`）：完整 MP3 合成与 M4B 导出需要；仅导入、整理和审阅文字不需要。
- **文本模型**：在应用"本地设置"中连接；使用本机 Agent 协作或原文朗读时不必配置。
- **桌面打包**：见[桌面版发布说明](docs/desktop-release.md)。

## 技术栈

| 层 | 实现 |
| --- | --- |
| 后端 | Python · FastAPI · SQLite · Pydantic |
| 前端 | 原生 HTML / CSS / JavaScript（无构建步骤） |
| 语音合成 | edge-tts（默认）及 OpenAI 兼容 TTS 接口 |
| 音频处理 | FFmpeg（MP3 拼接、M4B 有声书与章节标记） |
| 桌面化 | PyInstaller 打包 · pywebview |

## 数据与隐私

- **本地存储**：文章、项目、进度和生成结果默认保存在本机。桌面版路径为 `~/Library/Application Support/LawFlow/data/`；从源码运行使用仓库下的 `data/`。导出目录可在应用中设置。
- **网络边界**：桌面应用监听局域网，但局域网设备只能访问扫码领取的收听页（`/m/` 一次性链接），无法访问声息的其他功能。声息目前没有公共业务后端。
- **第三方服务**：使用外部文本模型或语音服务时，相关内容会发往用户选择的服务。调用前请确认材料有权发送。
- **网页检索**：公开网页检索仅用于发现候选来源，用户确认导入后才会用于后续整理。

## 当前边界与路线图

**已支持：手机扫码收听。** 在音频页生成二维码后，手机与电脑连同一个 Wi-Fi 时扫码，即可在浏览器里按章收听、边听边看文稿（自动随播放滚动）、±15 秒快进后退、下载章节、续听上次进度；也可一键下载整书 ZIP（逐章 MP3 + 讲稿 TXT），解压后离线收听。手机页还支持**离线缓存**：把章节音频存进手机浏览器，之后即使电脑关机，页面里已缓存的章节照样能听；离线时标记的「已学」会暂存，重新连上电脑后自动同步。在 iPhone Safari 里「分享 → 添加到主屏幕」，收听页会以独立图标全屏打开，接近原生 App 的体验。手机上标记的「已学」会同步回电脑。链接默认 7 天有效，可随时吊销，且只在声息运行时可访问——电脑退出或睡眠时，手机页会暂时打不开（已缓存或已下载到手机的内容不受影响）。

**尚未实现**：从外部网络（不同 Wi-Fi）收听——计划通过加密临时上传的中转实现，未完成；受浏览器限制，主屏幕图标重新打开时仍需声息在线加载页面本身，完全离线启动需等中转阶段；手机端暂时是网页，还不是可安装的原生应用。

M4B 带章节标记，但不能保证隔空投送后直接进入 iPhone“图书”；可先导入电脑的“图书”再通过访达同步到手机。

移动端路线图（标记"未实现"的阶段均无确定发布日期）：

| 阶段 | 状态 |
| --- | --- |
| 1. 逐章音频与章节信息 | ✅ 已实现（分章学习逐章合成 MP3） |
| 2. 局域网扫码领取 | ✅ 已实现（一次性链接 + 二维码，可吊销） |
| 3. 手机网页收听 | ✅ 首版已实现（按章播放、倍速、下载、断点续听、已学回传） |
| 4. 外部网络中转 | 未实现：加密临时上传 + 可过期中转链接，支持不在同一 Wi-Fi 时收听 |
| 5. 离线与安装 | 未实现：PWA 离线缓存、添加到主屏幕 |
| 6. 真机验收后扩展 | 未实现：锁屏播放与耳机控制真机验证；必要时再评估独立 iOS 客户端 |

扩展到外部网络的中转路径预计需要少量按用量计费的临时存储和网络流量；只有用户主动使用时才涉及上传。加密、链接失效和数据删除机制会先于对外开放完成。

## 开发

```bash
# 运行测试
python3 -m unittest discover -s tests -v

# 前端脚本语法检查
node --check app/static/app.js
```

项目结构：

```
app/
  main.py          # FastAPI 后端：材料解析、大纲/讲稿生成、TTS、导出
  static/          # 前端界面（无构建步骤）
  version.py       # 版本号唯一来源
skills/lawflow/    # 供外部 Agent 使用的 Skill
scripts/           # 打包与发布脚本
tests/             # 单元与 API 测试
docs/              # 发布与工作流文档
```
