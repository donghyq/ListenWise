# 声息 Shengxi

**把没有时间读完的东西，带到路上。**

声息是一款本地优先的桌面听读工具，把收藏的公众号文章、报告和笔记变成适合通勤与碎片时间收听的内容。你可以保留原文直接朗读，也可以让 AI 拆成章节、改写成播客讲稿——所有生成内容经你确认后才合成音频，数据与密钥始终保存在本机。

## 下载与安装

前往 [Releases（v0.1.2）](https://github.com/hey-elaine/lawflow/releases/tag/v0.1.2) 下载对应平台安装包：

| 平台 | 安装包 / 打开方式 | 说明 |
| --- | --- | --- |
| **macOS（Apple Silicon）** | `Shengxi-0.1.2-macOS-arm64.dmg` | 拖入「应用程序」打开。因采用临时签名，首次启动若提示无法验证开发者，请在访达「应用程序」中**按住 Control 点击「声息」→ 打开**。合成 MP3 / M4B 需安装 FFmpeg（`brew install ffmpeg`）。 |
| **Windows（10 / 11，64 位）** | `Shengxi-0.1.2-win64.zip` | 解压到任意文件夹，双击 `Shengxi.exe` 即可运行（包内已内置便携版 FFmpeg，无需额外配置）。 |
| **手机端（iOS / Android）** | 无需安装 App | 在电脑端点击「带到手机听」，手机连同一 Wi-Fi 扫码即可收听；支持离线缓存与整书 ZIP 下载。 |

## 三分钟上手

```
粘贴链接 / 拖入文档 ──► 选「原文朗读」或「播客风改写」 ──► 20 秒试听第 1 章 ──► 点句收听 / 划词修改 ──► 扫码带到手机听
```

1. **导入并核对**：在书架顶部粘贴公众号/网页链接（可展开检查全文与结尾是否完整），或拖入 PDF / DOCX / TXT / Markdown，也可直接粘贴正文。
2. **选择怎么听**：
   - **原文朗读**：不改写文字，直接用系统免费离线语音或 Edge TTS 生成音频，无需配置大模型。
   - **播客风改写（默认）**：AI 按目录或逻辑分章成稿。提供三档深度：**原文转译**（保留全部关键信息）/ **提炼**（压缩速听）/ **扩充**（补充背景讲透）。
3. **先试听再全篇生成**：确认章节大纲后，可先点「先生成第 1 章试听」花约 20 秒验证风格与音色；满意后点「继续生成剩余章节」，从第 2 章断点续写。
4. **声文同频与随手润色**：播放时当前句高亮并自动居中滚屏，**点击正文任意句子可直接从该句开始听**；划选不满意的段落即可触发 AI 精简或重写，对照候选稿确认后自动更新该章音频。
5. **带到路上听**：点击项目右上角「带到手机听」，扫码即可带走单本书或整座书架。点「离线缓存」或「下载全部（MP3 + 讲稿）」后，电脑关机也能继续听，听完自动同步「已学」进度。

## 核心体验亮点

- **声文同频点读与全局迷你吧台**：切去查素材或返回书架时，窗口底部自动浮起迷你播放条；支持桌面快捷键（`Space` 播放/暂停、`←/→` ±15 秒、`[/]` 切章、`M` 标记本章已学）与睡眠定时。
- **事实核对与来源回溯**：一键提取原文中的日期、数字和法规名称，核对讲稿是否遗漏；每章均可随时对照原文段落。
- **书架整理与自动收件箱**：支持收藏夹、系列合集筛选、画廊/紧凑列表视图切换与批量管理；支持 RSS 每日速听订阅与本地文件夹自动监听导入。
- **多格式音频与文档导出**：支持分章/整篇 MP3、带章节标记的 M4B 有声书、音频响度归一与首尾淡入淡出，以及 Markdown / DOCX 讲稿导出。

## AI 协作与数据隐私

原文朗读完全不依赖大模型。使用播客风改写时，任选以下一种方式即可：

| 协作方式 | 适用场景 | 材料去向 |
| --- | --- | --- |
| **连接模型 API** | 在「设置」中填写 DeepSeek、OpenAI 或兼容网关密钥 | 仅在你勾选允许后，所选材料才会发送至你配置的服务 |
| **外部 AI 助手免配置协作** | 点击「复制给 AI 助手」，粘贴到网页版 ChatGPT / 千问生成后再粘回声息 | 仅你主动复制的材料进入对应助手，本机无需配置密钥 |
| **本机 Agent（`$lawflow`）** | 安装仓库内的 [声息 Skill](skills/lawflow/SKILL.md)，在支持 Skill 的 Agent 中直接调用 | 由你使用的 Agent 环境决定，声息负责受控读写与审阅 |

- **本地存储**：文章、进度、音频与密钥仅保存在本机（macOS：`~/Library/Application Support/LawFlow/data/`；Windows：`%LOCALAPPDATA%\LawFlow\data`）。
- **局域网隔离**：局域网设备仅能访问带时效 Token 的手机收听页（`/m/`），无法访问桌面端任何管理或设置接口；链接默认 7 天有效且可随时吊销。
- **审阅边界**：系统生成的「待核验提示」仅用于辅助标出疑点，不代表已完成事实核查，不能直接替代专业判断。

## 当前边界与路线图

- **当前边界**：手机端首次打开收听页需与电脑处于同一 Wi-Fi 且声息正在运行（缓存音频或下载整书 ZIP 后可离线播放）；跨网络（非同一 Wi-Fi）中转与可安装原生手机客户端尚未实现。
- **后续规划**：跨项目通勤播放队列、书架讲稿全文搜索、加密临时外网收听中转。

## 从源码运行与开发

环境要求：Python 3.10+，如需音频合成请安装 FFmpeg。

```bash
git clone https://github.com/hey-elaine/lawflow.git
cd lawflow
python3 -m venv .venv
source .venv/bin/activate   # Windows PowerShell: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --host 127.0.0.1 --port 8080
```

浏览器打开 `http://127.0.0.1:8080` 即可使用。

```bash
# 运行全量测试与前端语法检查
python3 -m unittest discover -s tests -v
node --check app/static/app.js
```
